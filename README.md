# Command Center (laptop app)

Izaiah's Command Center as an installable app for Chromebook. Data is saved on the computer, not in this repo.

- Install: open https://iw7seven-7.github.io/command-center/ in Chrome, then click the install icon in the address bar.
- Backup: watch → Laptop app → Save a backup file. Keep the file on a USB drive to move everything to another computer.
- Restore: watch → Laptop app → Restore from a backup file.
